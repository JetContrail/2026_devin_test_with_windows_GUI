# DrawingApp 利用者マニュアル

DrawingApp は、下絵画像の上に描画できる Windows 向けのお絵描きアプリです。下絵と描画は別のレイヤーとして扱われるため、描画だけを透過 PNG として保存することも、下絵と重ねた 1 枚の画像として保存することもできます。

## 1. 動作環境と起動

| 項目 | 内容 |
|----|----|
| OS | Windows 10 / 11 (x64) |
| 必要なソフト | なし (配布用 exe は .NET を同梱) |

1. 配布された zip を展開します。
2. `DrawingApp.exe` をダブルクリックします。
3. 初回に「Windows によって PC が保護されました」と表示された場合は、「詳細情報」→「実行」を選びます (署名していないため)。

起動すると、白い 1280x720 のキャンバスが表示されます。

## 2. 画面構成

```
┌ メニュー: ファイル / 編集 / ツール ───────────────────────────┐
├ ツールバー: [ペン][点][消しゴム] | ペン[5px▼] 点[5px▼] 消しゴム[20px▼] | 倍率: 100% ┤
│                                                                  │
│                     キャンバス (下絵 + 描画)                       │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

| 場所 | 内容 |
|----|----|
| ファイル | 下絵読込、描画のみ保存、合成保存 |
| 編集 | 元に戻す (Undo)、やり直し (Redo) |
| ツール | ペン、点、消しゴムの切り替え (選択中のツールにチェック) |
| ツールバー左 | ツールの切り替え |
| ツールバー中央 | ペン・点・消しゴムのサイズ選択 (現在の値を表示) |
| ツールバー右 | 現在の表示倍率 |

## 3. 下絵を読み込む

1. 「ファイル」→「下絵読込」を選びます。
2. PNG / JPG / JPEG の画像を選びます。

- 下絵は背景レイヤーになり、ペンや消しゴムで変更されることはありません。
- キャンバスの大きさは下絵の大きさに変わります。それまでの描画は左上をそろえて残り、はみ出した部分は切り捨てられます。
- 読み込むと、元に戻す / やり直しの履歴は消え、表示は倍率 100%・左上に戻ります。
- 読み込める画像は 4096x4096 ピクセルまでです。読み込めない画像を選ぶとエラーメッセージが表示され、キャンバスはそのまま残ります。

## 4. 描く

ツールはツールバーまたは「ツール」メニューで切り替えます。描画の色は黒です。

| ツール | 操作 | サイズ |
|----|----|----|
| ペン | ドラッグしてフリーハンドで線を描く | 1 / 3 / 5 / 10 / 20 px |
| 点 | クリックした位置に点を 1 つ置く (ドラッグしても増えない) | 1 / 3 / 5 / 10 / 20 px |
| 消しゴム | ドラッグした部分の描画を消す (下絵は消えない) | 10 / 20 / 50 px |

サイズはツールバーの各ツールのドロップダウンで選びます。ツールごとに別々に覚えています。

## 5. 元に戻す / やり直し

| 操作 | ショートカット | メニュー |
|----|----|----|
| 元に戻す | Ctrl+Z | 編集 → 元に戻す |
| やり直し | Ctrl+Y | 編集 → やり直し |

- ペン 1 本、点 1 つ、消しゴム 1 回のドラッグがそれぞれ 1 操作です。
- 少なくとも直近 20 操作 (通常は 50 操作) まで戻せます。
- 元に戻した後に新しく描くと、やり直しの履歴は消えます。
- 戻せる操作がないときは、メニューがグレーアウトします。

## 6. 拡大・縮小と表示位置の移動

| 操作 | 方法 |
|----|----|
| 拡大 / 縮小 | マウスホイール (1 目盛りで 1 段階、マウスカーソルの位置を中心に拡大縮小) |
| 表示位置の移動 (パン) | 中ボタンでドラッグ、または Space キーを押しながら左ボタンでドラッグ |

- 倍率は 10 / 15 / 20 / 25 / 33 / 50 / 67 / 75 / 100 / 125 / 150 / 200 / 300 / 400 / 600 / 800 % の 16 段階です。
- Space キーを押しながらのドラッグでは描画されません。

## 7. 保存する

| メニュー | 保存される内容 | 既定のファイル名 |
|----|----|----|
| ファイル → 描画のみ保存 | 描画レイヤーだけ。下絵は含まれず、何も描いていない部分は透明 | `drawing.png` |
| ファイル → 合成保存 | 下絵の上に描画を重ねた 1 枚の画像 | `composite.png` |

- 保存形式は PNG です。
- 保存はいったん別の一時ファイルに書いてから置き換えるため、失敗しても既存のファイルが壊れることはありません。保存できなかった場合はエラーメッセージが表示されます。

## 8. オートセーブ

起動中は 60 秒ごとに描画を自動保存します。前回の保存以降に変更がなければ保存しません。

| 項目 | 内容 |
|----|----|
| 保存場所 | `%LOCALAPPDATA%\DrawingApp\AutoSave` (例: `C:\Users\<ユーザー名>\AppData\Local\DrawingApp\AutoSave`) |
| 保持数 | 最新 10 回分。古いものは自動で削除 |
| 内容 | 保存日時 (UTC) の名前のフォルダに、`drawing.png` (描画レイヤー、透過 PNG) と `manifest.json` (保存日時・大きさ・下絵のファイルパス) |

- 下絵の画像そのものは保存されません (ファイルの場所だけを記録します)。
- アプリを終了するときには保存しません。
- 自動保存したデータを読み込む画面はありません。アプリが異常終了した場合は、保存場所のフォルダから `drawing.png` を取り出してください。

## 9. 困ったとき

| 症状 | 対処 |
|----|----|
| 起動時に SmartScreen の警告が出る | 「詳細情報」→「実行」を選ぶ |
| 下絵が読み込めない | PNG / JPG / JPEG で、4096x4096 ピクセル以下か確認する |
| 描いた内容を見失った | 下絵を読み込み直すと表示が 100% に戻る (描画は残る) |
| 描画を誤って消した | Ctrl+Z で元に戻す |
