## 受け入れ基準

各 PBI の詳細な受け入れ基準は対応する GitHub Issue に記載する。
全体の完了条件は「Definition of Done」(下記) とする。

## Definition of Done

- [ ] .NET 10 でビルド成功 / Compiler Warning 0件
- [ ] 全 Unit Test 成功 / GitHub Actions 成功 / カバレッジ 80% 以上
- [ ] 下絵読込・ペン描画・点描画・消しゴム・レイヤー分離
- [ ] 描画のみ保存・合成保存 (PNG)
- [ ] Undo / Redo・Zoom / Pan・オートセーブ
- [ ] README.md / Architecture.md / UserManual.md 作成済

## 仮定 (Assumptions)

要求仕様で明示されていない点について以下の仮定を置く。変更が必要な場合は Issue で議論する。

| ID | 仮定 | 関連 |
|----|----|----|
| A1 | 描画レイヤーはラスタ (BGRA32 ピクセルバッファ) で保持する。消しゴムの「描画レイヤーのみ消去」と PNG 出力を素直に実現するため。将来の SVG 出力用に操作ログ (ストローク座標列) も保持できる設計とする | PBI-06, 13 |
| A2 | 下絵未読込時の既定キャンバスは 1280x720、背景は白表示 | PBI-06 |
| A3 | 下絵読込時、キャンバスサイズは下絵サイズに合わせる。既存描画は左上基準で保持し、はみ出しは切り捨て | PBI-12 |
| A4 | 下絵読込は Undo 対象外 (要求の対象は描画/点描画/消去のみ)。読込時に履歴をクリアする | PBI-12, 16 |
| A5 | Undo 履歴の既定保持数は 50 (要求: 20以上) | PBI-16 |
| A6 | パンは中ボタンドラッグと Space+ドラッグの両方を実装する | PBI-18 |
| A7 | ズームはカーソル位置基準、ホイール1ノッチで約1.25倍 (段階テーブル方式) | PBI-17 |
| A8 | オートセーブ内容は描画レイヤー PNG + メタデータ JSON。前回保存から変更が無い場合はスキップ。復元 UI は初版スコープ外 | PBI-19 |
| A9 | 初版の線描画はアンチエイリアス無し (ハードエッジ円ブラシ)。将来 AA を追加可能な Rasterizer 抽象とする | PBI-07 |
| A10 | ソリューション形式は .NET 10 標準の `.slnx` | PBI-02 |
| A11 | カバレッジ計測対象は Core / Infrastructure / ViewModel。XAML View と起動コードは除外 | PBI-20 |
| A12 | CI ランナーは WPF ビルドのため `windows-latest` | PBI-05 |
